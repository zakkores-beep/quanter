Aon Sprint

Practice for the Fidelity numerical and verbal tests in Aon's format: six tabs, 18 True / False / Cannot say statements, 6 minutes. Every attempt builds fresh data, so you can take it as often as you like.

Before every answer

  1. Find the tab first, then the exact row and column.
  2. Check the footnotes: surcharges are added on top, once per parcel.
  3. Match chart colours to the legend, not to the order of the slices.
  4. If a line has no labels, build it from the formula under the chart.
  5. A period, price or reason that isn't on any tab means Cannot say.
  6. Close is not equal: £27.70 is not £37.70.
  1. Find the sentence the statement is built on, then compare word by word.
  2. A swapped detail (role, body, country, number) makes it False.
  3. "Only", "all", "always" against a text that lists more options: False.
  4. A real topic plus a detail no tab mentions (a time frame, a purpose, a country): Cannot say.
  5. Rules go one way: "where options, also real estate funds" does not work in reverse.
  6. Two-part statements need both halves true.
