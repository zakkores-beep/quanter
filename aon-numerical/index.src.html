Numerical Sprint

Practice for the Fidelity numerical test in Aon's format: six data tabs, 18 True / False / Cannot say statements, 6 minutes. Every attempt builds fresh data, so you can take it as often as you like.

Mode

Keys: T F C answer, 1–6 tabs, ← → move

Before every answer

  1. Find the tab first, then the exact row and column.
  2. Check the footnotes: surcharges are added on top.
  3. Match chart colours to the legend, not to the order of the slices.
  4. If a line has no labels, build it from the formula under the chart.
  5. A period, price or reason that isn't on any tab means Cannot say.
  6. Close is not equal: £27.70 is not £37.70.
